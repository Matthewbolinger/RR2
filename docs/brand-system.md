# Brand System

## Platform

- Primary slogan: **Built Above Standard.**
- Supporting statement: **Premium roofing and restoration for homeowners who expect more.**
- Operational proof: clear before work begins; built right where it matters; communication without chasing; respect for the property; verified before completion.

The legacy “Strong Roofs. Safe Homes. Done Right.” line is not used.

## Palette

| Token | Value | Use |
| --- | --- | --- |
| Rich black | `#0D0D0D` | Primary environment |
| Charcoal | `#1A1A1A` | Layered dark surfaces |
| Warm gold | `#C7A24A` | Primary actions and selected emphasis |
| Tan | `#D2B48C` | Reserved supporting tone |
| Gray | `#555555` | Secondary copy support |
| Warm cream | `#F4F1EA` | Readable editorial sections |
| White | `#FFFFFF` | Primary dark-surface text |

Gold is restricted to CTAs, eyebrows, select icons, rules, and short headline emphasis. It is not used for long small text on white.

## Typography

- Display: Bebas Neue with Arial Narrow/Impact fallback
- Body/interface: Montserrat with Arial fallback

Display type is limited to short headlines, major statistics, and service titles. Body copy, navigation, forms, and long labels use Montserrat.

## Layout

- Maximum shell: 1,280px
- Desktop: disciplined multi-column editorial grids
- Tablet: two-column transitions
- Mobile: single-column flow and persistent conversion bar
- Corners: square; no generic pill or glass components
- Borders: thin controlled rules
- Motion: image scale and directional-arrow movement only, removed under reduced-motion preference

## Pattern

`public/assets/footer-brand-pattern.jpg` is the client-supplied RR, raccoon, and star textile used behind the sticky header and footer with separate controlled dark overlays. The header uses a tighter horizontal scale and restrained gold edge for brand energy; the footer repeats horizontally and vertically across desktop and long mobile layouts.

`public/assets/brand-pattern.svg` remains the restrained code-native pattern used in smaller dark editorial sections. It can be replaced when an approved compact source pattern is supplied.
